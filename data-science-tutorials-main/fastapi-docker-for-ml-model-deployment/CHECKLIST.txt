🛠️ TROUBLESHOOTING:
─────────────────────
Port in use?
  → Use different port: python -m uvicorn app.main:app --port 8001

Frontend not showing?
  → Check static/index.html exists
  → Check server is running
  → Clear browser cache

API errors?
  → Check /docs for interactive testing
  → Read FRONTEND_README.md
  → Check browser console (F12)
